# NGO CONNECT 🤝

## Community Engagement Project (CEP)

### 📌 About the Project
NGO CONNECT is a Community Engagement Project focused on the NGO sector. This repository contains the project report and presentation materials prepared as part of the CEP academic work.

### 🎯 Project Objectives
- Present the NGO CONNECT project and its purpose.
- Document the project work and related activities.
- Organize the project report and presentation materials in one place.
- Support project review, evaluation, and presentation.

### 📂 Repository Contents

| File Name | Description |
|---|---|
| `Presentation1_NGO-CONNECT.pptx` | Initial project presentation |
| `Report_NGO-CONNECT.docx` | Detailed project report |
| `FinalPresentation_NGO-CONNECT.pptx` | Final project presentation |

### 🛠️ Tools and Technologies
The project documentation and presentations are available in Microsoft Office file formats.

- Microsoft PowerPoint — Presentations
- Microsoft Word — Project report
- GitHub — Project file storage and version control

### 📖 How to Access the Files
1. Open the required file from this repository.
2. Download the file to your computer.
3. Open `.pptx` files using Microsoft PowerPoint or a compatible presentation application.
4. Open the `.docx` file using Microsoft Word or a compatible document application.
